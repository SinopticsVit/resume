## 5.2. Логистические маршруты Китай → Россия

| Маршрут | Origin → Destination | Transit time | Cost (indicative) | Best for |
|---|---|---|---|---|
| **Морской** | Qingdao/Shanghai/Ningbo → SPb/Novorossiysk | 40–55 дней | USD 2 000–4 000/FEU | Bulk, non-urgent |
| **Ж/д (Trans-Siberian)** | Xi'an/Chengdu/Chongqing → Moscow/Elektrougli | 14–22 дня | **USD 1 500–3 500/20GP** | Mid-volume, balanced |
| **Ж/д (via KZ)** | Yiwu → Bely Rast/Moscow | 18–25 дней | USD 2 000–4 000/FEU | Южный Китай → РФ |
| **Авиа** | Guangzhou/Shanghai → Moscow | 3–7 дней | USD 3–8/kg | Samples, urgent |
| **Авто** | Manzhouli/Zabaykalsk | 7–14 дней | Variable | Cross-border, small lots |

**Ж/д статистика 2024:**
- China-Russia routes: **88,6%** transit через KZ/RU/BY.
- Top routes: Xi'an–Elektrougli (11%), Chongqing–Elektrougli (9%), Chengdu–Kolyadichi (22%).
- Toys/sporting goods: **+1 п.п.** share в container mix 2024.
- Post-Red Sea (2024): rail demand **+37%**, prices up «several times» on key routes.

## 5.4. Экономия от прямой работы с фабриками

| Статья | Типичная маржа посредника | Экономия RO |
|---|---|---|
| Trading company/agent | 5–15% | Direct factory access |
| QC failures / returns | 3–8% of COGS | On-site inspection |
| Sample lead time | 2–4 weeks via agent | 3–7 days direct |
| MOQ negotiation | Standard | Custom MOQ for DM volume |
| **Совокупная целевая экономия** | — | **8–15%** on addressable spend |

## 5.5. Функции офиса (Operating Model)

| Функция | Описание | KPI |
|---|---|---|
| **Sourcing** | Поиск OEM/ODM, переговоры, контракты | New suppliers/quarter |
| **QC Inspection** | Pre-shipment inspection (AQL 2.5) | Defect rate <1,5% |
| **Sample management** | Showroom, sample library | Time-to-shelf |
| **Supplier audit** | Social compliance, capacity | Audit score |
| **Logistics coordination** | Booking, documentation, customs | On-time delivery |
| **Trend scouting** | Canton Fair, Yiwu market, 潮玩 | SKU pipeline |
| **IP protection** | TM registration, NDA enforcement | Zero IP incidents |

## 5.6. Best practices (кейсы)

| Компания | Модель | Урок для DM |
|---|---|---|
| **IKEA Trading (Иу/Гуанчжоу)** | Regional sourcing offices + strict QC | Long-term supplier relationships |
| **Carrefour Global Sourcing** | Hub in Shanghai + category teams | Category-specialist buyers |
| **X5 Import (杭州)** | RO-equivalent + direct import team | **Ближайший аналог:** 1 500+ suppliers, 70+ countries |
| **Ozon Global** | China office for marketplace sellers | Cross-border model |

**X5 Import — референс:** 阿勒维埃（杭州）采购有限公司 (Hangzhou) — прямой закупочный офис для российского ритейла. Модель доказала эффективность для FMCG/non-food.

# Resume

Two source files, always in sync:

| File | Purpose |
|------|---------|
| `resume.md` | Plain-text source — edit this first |
| `resume.html` | Styled version — open in browser, print → Save as PDF |

## Workflow

1. Edit `resume.md` (or directly in `resume.html`).
2. Open `resume.html` in Chrome/Edge.
3. **Ctrl + P** → *Save as PDF* → Destination: "Save to PDF" → no margins, background graphics ✓.

## Structure

```
resume/
├── README.md
├── resume.md        ← canonical source
└── resume.html      ← print-ready, zero dependencies
```
